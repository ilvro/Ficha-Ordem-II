# Ficha Ordem Paranormal II — interface Mini Kraken

Reprodução local e responsiva da ficha do playtest Alpha de Ordem Paranormal RPG 2, seguindo a estética de **A Maldição do Ídolo de Pedra** usada no Mini Kraken.

## Rodar

```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite. A ficha salva alterações no `localStorage` do navegador.

## Incluído

- layout de três colunas com faixas rasgadas, tipografia editorial e fundo azul-petróleo;
- Físico, Mente e Emoção apresentados em SVGs facetados próprios para d4, d6, d8, d10, d12 e d20;
- PV e PD em marcadores individuais, sólidos e editáveis;
- tabela de perícias com treinamento, atributo e dados;
- painéis de História, Itens e Habilidades;
- editor de cards com coleção, título, tipo, ícone, cor, imagem, apresentação, conteúdo, cargas e botão de rolagem;
- cards reordenáveis por controles ou arrastar e soltar, recolhíveis e duplicáveis;
- persistência local e resultado de dados em modal.

Este projeto é uma implementação independente para uso local. Marcas e conteúdos de Ordem Paranormal e Mini Kraken pertencem a seus respectivos titulares.
